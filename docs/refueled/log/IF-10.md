## Windows

Unverändert im Verhalten: `pf_dump_signal_install` speichert den Callback, `pf_dump_other_threads`
tastet jeden fremden Thread mit `pf_thread_sample` ab (SuspendThread/GetThreadContext, synchron).
Ein `kill -USR2`-Gegenstück gibt es unter Windows nicht.
