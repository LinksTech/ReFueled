## Was der Test deckt

| Fall | Gast-Routine | Host-Gegenstück |
|---|---|---|
| (a) 8 Ganzzahlen (6 Register + 2 Stack), 8 Double in xmm0–7, 2 Double auf dem Stack | `guest_call_mix` | `ABI uint64_t host_mix(...)`, Prüfsumme |
| (a) float in xmm0, double in xmm1, int32 | `guest_call_fmix` | `host_fmix` |
| (b) Struct > 16 Byte per sret (rdi = Zeiger, rax = Zeiger) | `guest_call_big` | `host_make_big` |
| (b) 2 INTEGER-Achtbyte in rax:rdx | `guest_call_small` | `host_make_small` |
| (b) 2 Double in xmm0:xmm1 | `guest_call_dpair` | `host_make_dpair` |
| (b) {uint64, double} in rax:xmm0 | `guest_call_mixed` | `host_make_mixed` |
| (b) Structs als Argument (32 Byte auf dem Stack, 16 Byte in rdi:rsi, 2 Double in xmm0:xmm1) | `guest_call_take` | `host_take_structs` |
| (c) Rückruf Host→Gast über `ABI`-Zeiger; Gast zerstört xmm6–15, rdi, rsi, sichert rbx, rbp, r12–r15 | `guest_clobber`, `guest_invoke_probe` | Prüfung der Register nach dem Aufruf |
| (c) 12 Double bleiben im Host über den Rückruf lebendig (unter Win64 in xmm6–15) | – | `live_across_callback` (noinline) |
| (d) rsp ≡ 0 mod 16 vor dem Aufruf, 16 verschiedene Stack-Versätze; `_Alignas(16)`, `__builtin_frame_address`, `movaps`; Asm-Hilfe `guest_get_rsp` | `guest_call_aligned` | `host_check_align` |
| (d) Eintritt Host→Gast mit ausgerichtetem Stack | `guest_entry_misalign` | Prüfung in `main` |

Red Zone wird nicht getestet (Paket RZ). Zeiger auf Gastfunktionen laufen über `volatile`-Variablen
(`g_entry_ptr`, `g_clobber_ptr`), damit der Compiler den Aufruf nicht zu einem direkten Aufruf
auflöst (gcc tat das bei `-O2`).

```
wsl -e sh -c 'cd /mnt/c/nitro-ps4-wt/F7 && gcc -std=c11 -O2 -Wall -Wextra -Werror \
  tests/refueled/test_sysv_abi.c tests/refueled/sysv_caller.S -o out/t_sysv-O2 && ./out/t_sysv-O2'
-> test_sysv_abi: 149 checks passed
dasselbe mit -O0
-> test_sysv_abi: 149 checks passed
```

Nicht-ELF-Pfad: `gcc -c -x assembler-with-cpp -U__ELF__ tests/refueled/sysv_caller.S` übersetzt
(Makros `CALL`/`FUNC`/`ENDF` ohne `.type`/`.size`/`@PLT`, ohne `.note.GNU-stack`). Dabei entsteht
weiter ein ELF-Objekt: **offen für CLANG64**, ob der echte COFF-Lauf sauber ist (Fragen dort:
`movabs`, `movq %r10,%xmm`, `call sym` ohne `@PLT`, `.p2align`, Lokale Labels gibt es nicht).

### Zusatzprobe: Win64 als Standard-ABI unter Linux (nicht Teil der Abnahme)

`gcc -mabi=ms` macht Win64 zur Standard-ABI; alles ohne `ABI` wird dann wie unter Windows
übersetzt. Dafür kennt der Test ein Makro `F7_MSABI_TRIAL`: es nimmt libc heraus (SysV) und nutzt
zwei normal übersetzte Hilfsfunktionen `f7_fail`/`f7_done` (nicht eingecheckt, `out/f7_shim.c`):

```
gcc -std=gnu11 -Wall -Wextra -mabi=ms -fno-builtin -fno-tree-loop-distribute-patterns \
    -DF7_MSABI_TRIAL -O2 tests/refueled/test_sysv_abi.c tests/refueled/sysv_caller.S out/f7_shim.o
-> 149 checks passed (-O2 und -O0)
```

Mutationen (ein `ABI` entfernt, mit `-mabi=ms -O2`) schlagen alle fehl, der Test ist also
empfindlich: `host_mix` (falsche Argumente), `host_make_big` (Absturz), `host_make_small`
(Absturz), `host_take_structs` (Absturz), `host_fmix` (falscher int), `host_check_align` und
`guest_clobber` (Ausrichtung/Argument), `GuestFn`-Typedef ohne `ABI` (Rückruf liefert falsches
Ergebnis). Das ist ein starker Hinweis, aber kein Ersatz für den Lauf mit clang unter Windows
(clang kennt dort zusätzlich TEB/SEH/Prolog-Unterschiede).

## Offen für den Abnahmelauf (nach F3, Windows, clang)

- Build: `clang -std=c11 -O2 -Wall -Wextra -Werror tests/refueled/test_sysv_abi.c tests/refueled/sysv_caller.S`
  und `-O0`, Ausgabe muss `test_sysv_abi: 149 checks passed` sein.
- COFF-Assemblierung der `.S`-Datei (siehe oben).
- Die Datei nutzt `emmintrin.h` (SSE2 ist bei x86-64 immer vorhanden) und `_Alignas`; beides ist mit
  clang auf Windows verfügbar.
- Eintrag in `tests/CMakeLists.txt`/Build-Skript: gehört nicht zu F7 (Dateiliste des Pakets), Opus.
