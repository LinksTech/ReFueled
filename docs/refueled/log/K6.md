# Paket-Log K6 – pf_thread Windows, Stackwechsel, pf_jmp (Opus)

Verhaltensabweichung Linux: keine (nur Windows)

- `pf_jmp_win32.S` (ersetzt den F2-Stub pf_jmp_win32.c): registerbasiertes setjmp/longjmp,
  Windows-x64-Nichtflüchtige (rbx rbp rdi rsi rsp r12–r15 rip, MXCSR + x87-CW, xmm6–15), Layout
  PF_JMP_* aus pf_win32_internal.h (gleiches Layout liest pf_fault_resume_at, K7). Blattfunktionen
  ohne RSP-Änderung bis zum Sprung, daher ohne Unwind-Daten.
- `pf_stack_win32.S`: `pf_call_guest_on_stack` (SysV-Aufruf auf Gast-Stack, sichert zusätzlich
  rdi/rsi/xmm6–15, die der SysV-Gast zerstören darf) und `pf_win32_run_on_stack` (Win64-Aufruf
  für pf_thread_create_on_stack). Beide setzen für die Dauer NT_TIB.StackBase (gs:8),
  StackLimit (gs:0x10) und TEB.DeallocationStack (gs:0x1478) auf den neuen Stack und stellen
  sie danach wieder her (D7). Prologe mit .seh_pushreg/.seh_setframe (RBP), damit Stack-Walks vom
  Gast-Stack zum Host-Stack zurückfinden.
- `pf_thread_win32.c`: create_on_stack (winpthreads-Thread mit 256 KiB Host-Stack, Wechsel per
  pf_win32_run_on_stack), GetCurrentThreadStackLimits, GetCurrentThreadId, Set/GetThreadDescription
  (zur Laufzeit geladen), THREAD_PRIORITY_IDLE, GetProcessAffinityMask, GetThreadTimes,
  Toolhelp32-Thread-Liste mit Namen, Abtasten per SuspendThread + GetThreadContext + ResumeThread
  (Rückruf auf dem abtastenden Thread; sich selbst abtasten → PF_EINVAL; unbekannte tid → PF_ENOENT).
- `test_thread.c`: Windows-Teil (VirtualAlloc-Stack, voller Name, Abtasten über pf_context_get auf
  beiden Plattformen, Rückruf-Thread je Plattform, Patch-Erwartung je Plattform).
- `test_stubs.c`: nur noch echte Stubs (pf_gpu_memory_in_use, pf_handle_map*); vorher rief er auch
  die inzwischen echten pf_process/pf_fs-Funktionen auf, darunter pf_restart_through_launcher –
  unter Windows hätte `build-windows.sh --test` den Testprozess endlos neu gestartet.

  des Ziels, Ziel läuft danach weiter), Selbst-/Fremd-tid, Idle-Priorität: `14 checks, 0 failed`.
  test_stubs: `7 checks passed`.
- Linux-Plattformtests unverändert grün (thread 41).
- Offen (CLANG64): Assemblieren als COFF inkl. .seh_*, test_thread unter Windows (Stackwechsel mit
  TEB-Grenzen, >64-KiB-Rahmen mit __chkstk), test_exception test_resume mit echtem pf_setjmp.
- Hinweis für K5 (runtime_thread.c): Gast-Threads dürfen nicht pthread_exit auf dem Gast-Stack
