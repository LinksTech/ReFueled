## errno-Zelle: Begruendung
- LOWHEAP Befund 2/4: der Gast bekommt die Adresse (`guest_error`, NID 9BcDykPmo1I, und
  `Libraries::Kernel::__Error` in gpu/shim/bbgpu.cpp:380, das nur `runtime_errno()` aufruft). Auf Windows
  liegt eine `_Thread_local`-Variable der Exe hoch. Jetzt liegt die Zelle im Low-Heap (TCB-Block).
- Eine Zelle im TCB-Block (nicht in den 256 TCB-Bytes selbst): die ersten 256 Bytes ab `tcb` sind
  Gast-Raum (TCB-Layout nicht vollstaendig bekannt), daher dahinter (`total += 16`).
- Kein Zugriff auf `current->tcb`: `runtime_errno()` wird auch von Threads ohne TCB gerufen, ein
  implizites `runtime_thread_current()` haette dort einen TCB samt GS-Setzen erzeugt.
- Grenzfall: ruft ein Thread `runtime_errno()` vor `attach()`, behaelt er seine Lazy-Zelle (Wert und
  Adresse bleiben stabil); die Zelle im TCB-Block bleibt dann unbenutzt.
